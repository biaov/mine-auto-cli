# node-switch

切换 Node.js 版本的工具 😆

## 全局安装

- 警告：此工具是为了简化 nvm 切换 Node.js 版本
- 比如 `ns 16.14.2` 等同于 `nvm use 16.14.2`
- 比如 `ns 16` 等同于 `nvm use 16.14.2`

```sh
npm i -g @biaov/node-switch
```

## 使用

```sh
ns <version>
```
